# Second Brain Albert Lutano

Tempat semua ide, tugas, janji, dan catatan saya mendarat, disusun dengan metode PARA.

| Folder / file | Isinya |
|---|---|
| `INBOX.md` | Tempat singgah untuk yang belum jelas mau ke mana. Dikosongkan saat review mingguan. |
| `JANJI.md` | Semua janji ke orang lain dan ke diri sendiri, lengkap dengan tenggat. |
| `1-proyek/` | Pekerjaan dengan hasil akhir dan tenggat yang jelas. Selesai, lalu pindah ke arsip. |
| `2-area/` | Tanggung jawab yang berjalan terus: ventura, klien, dan area hidup. |
| `3-sumber/` | Bahan referensi: buku, framework, kutipan, riset, ide mentah yang belum jadi proyek. |
| `4-arsip/` | Yang sudah selesai atau tidak aktif lagi. Tidak dihapus, hanya dipindah. |
| `review/` | Catatan review mingguan, satu file per minggu. |

## Cara pakai

Kirim saja ke thread second brain, dengan atau tanpa awalan:

- `ide:` masuk ke catatan area atau proyek yang cocok, atau ke `3-sumber/ide.md` kalau belum punya rumah.
- `tugas:` masuk ke bagian Tugas di proyek atau area terkait. Kalau ada tenggat, ikut dicatat.
- `janji:` masuk ke `JANJI.md`, dan ditautkan dari area atau proyeknya.
- `catat:` masuk ke catatan area atau proyek terkait, atau ke `3-sumber/` kalau sifatnya referensi.

Tanpa awalan, Claude menebak jenisnya. Kalau benar-benar ragu, masuk ke `INBOX.md` dulu.
